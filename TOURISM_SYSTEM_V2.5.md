# Tourism Information System V2.5 — Roi Et 20 Districts

## Features
- Tourism data for all 20 districts of Roi Et.
- REST API: `GET /api/tourism` with optional `q` and `category` filters.
- In-game tourism hub with search and category filtering.
- District detail cards with summary, image and attractions.
- Reuses Admin-managed cell images and attraction lists where available.
- Responsive UI for desktop and mobile.

## Data source note
The district list follows official Roi Et administrative information and Tourism Authority of Thailand references. Attraction content is a game-oriented tourism summary and should be reviewed by the Admin before public deployment.
